ALS WEB DEMO

Порт системы анимированных локомоций ALS-Community на веб-движок (Three.js)

Полная демонстрация портированной системы: трёхуровневая машина состояний движения (Grounded / InAir / Mantling / Ragdoll), movement-экшены (мантлы, кувырки, подъём), авто-определение аллюра с гистерезисом, три режима вращения (Velocity / Looking / Aiming), stance и view-режимы, оверлеи, камера с lag и подтягиванием к стенам — и главное: весь слой анимации идёт через ALSAnimationProviderInterface, а не через API конкретного рендера.

Попробуйте:
Подойдите к низкой стене → Q (LowMantle)
К ящику 2м → Q (HighMantle)
Проверьте:
Высокая серая стена — мантл отклоняется
На бегу E → ragdoll → GetUp
